# LiveOrder OS — Web

Landing oficial de LiveOrder OS: el sistema operativo del live commerce.

## Stack

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS v4
- Motion, GSAP y Lenis
- Fuentes: Bricolage Grotesque, Space Grotesk y JetBrains Mono

## Desarrollo

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run dev      # servidor local
npm run build    # build de producción
npm run start    # servir el build
npm run lint     # ESLint
```

## Estado

- Fase 01 — Brand foundation: tokens, tipografía, logo, primitives y preview del sistema (`/brand`).
- Fase 02 — Home real: header, hero con simulación live, narrativa del problema y CTA de acceso.
- Identidad alineada al producto: violeta de marca `#863BFF`, lima de acción `#C8FF3D` y coral live `#FF5C45`.
- Fase 03 — Demo interactiva del **flujo real** del prototipo en `#demo`: Pre-Live → Live Monitor → Post-Live → Auditoría, con parser FIFO, bloqueo de stock, CSV real y vista previa de WhatsApp. Especificación en [`docs/fase-3-demo.md`](docs/fase-3-demo.md).
